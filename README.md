# Week 2 Cybersecurity Practical Projects

## Project Overview

This repository documents my Week 2 practical cybersecurity exercises with NetworkWalks.

The project covers two areas: Footprinting and Reconnaissance, and Network Scanning using Zenmap.

The exercises provided an opportunity to apply cybersecurity concepts using practical tools, interpret results and document findings.

## Project Modules

### 1. PM1 – Footprinting and Reconnaissance

This module focused on gathering publicly available information about a target domain using different reconnaissance tools.

**Tools used:**
- WHOIS
- WhatWeb
- NSLookup
- cURL
- WAFW00F
- DNSRecon

**Activities performed:**
- Domain registration lookup
- Website technology identification
- DNS resolution and enumeration
- HTTP response header inspection
- Web Application Firewall identification

### 2. PM5 – Network Scanning with Zenmap

This module focused on identifying active devices within a local lab network.

**Tool used:**
- Zenmap (Nmap graphical interface)

**Activities performed:**
- Identifying local network configuration
- Performing a Ping Scan
- Discovering live hosts
- Reviewing IP and MAC address information
- Generating a network topology diagram

## Key Learning Outcomes

Through these exercises, I gained practical experience in:

- Understanding footprinting and reconnaissance techniques.
- Using command-line tools for information gathering.
- Interpreting DNS records and HTTP response headers.
- Performing basic network discovery.
- Understanding network topology and host identification.
- Documenting practical cybersecurity findings.

## Project Structure

- `PM1-Footprinting/` – Reconnaissance findings and sanitised evidence.
- `PM5-Zenmap-Scanning/` – Network scanning findings and sanitised evidence.

## Security and Privacy

Screenshots and supporting evidence shared publicly have been reviewed to avoid exposing personal information and private network identifiers.

Unredacted assessment evidence is retained separately and is not included in this public repository.
