# PM5 – Network Scanning with Zenmap

## Objective

To identify active devices within an authorised local lab network using Zenmap.

## Tool Used

- Zenmap (Nmap Graphical User Interface)

## Activities Performed

- Identifying local network configuration.
- Performing a Ping Scan.
- Discovering active hosts.
- Reviewing host and network information.
- Generating a network topology diagram.

## Practical Evidence

Screenshots showing the Zenmap scan configuration, scan results, discovered hosts and network topology are provided in this folder.

## Findings

The scan identified active devices within the local lab network. The topology view provided a visual representation of the discovered hosts.

## Learning Outcome

This exercise provided practical experience in basic network discovery, host identification and network topology visualisation using Zenmap.

## Security and Privacy

Personal information and sensitive private network identifiers have been redacted from the publicly shared screenshots.
